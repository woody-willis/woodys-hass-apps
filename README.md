# Woody's Home Assistant Apps

A Home Assistant app (add-on) repository.

## Install

1. In Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ → Repositories**.
2. Add this repository's Git URL.
3. Install an app from the list and configure it.

## Apps

- **[TorBoxarr](torboxarr/DOCS.md)**: TorBox as a qBittorrent/SABnzbd download client for the *arr apps.
